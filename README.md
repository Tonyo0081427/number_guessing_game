# Number Guessing Game

## Project Overview

This project is a command-line number guessing
game developed using Bash scripting and PostgreSQL.

Players must guess a randomly generated secret
number between 1 and 1000.

The application records player information and
game statistics in a PostgreSQL database.

## Technologies Used

- Bash Scripting
- PostgreSQL
- SQL

## Key Features

- User registration and username validation.
- Random number generation.
- Input validation for guesses.
- Tracks the number of guesses per game.
- Stores player statistics in PostgreSQL.
- Retrieves previous game records.

- Loops and user input validation
- SQL INSERT and SELECT statements
- Connecting shell scripts to PostgreSQL
- Managing user records and game statistics
